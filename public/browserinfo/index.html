關於您的瀏覽器環境…

您會看到此頁面，代表您目前的瀏覽器或裝置缺少「橋梁結構設計師」所需的關鍵功能。我們已盡力相容多數配備滑鼠（或觸控板）的裝置與主流桌面瀏覽器。

建議環境需求

非純觸控裝置：很抱歉，目前尚未支援完全沒有滑鼠指標的純觸控螢幕操作。
支援的主流瀏覽器：以下瀏覽器的最新版本皆可順暢使用：
  • Chromium 核心瀏覽器（最推薦）：
    • Google Chrome
    • Microsoft Edge
    • Chromium（開源版）
    • Opera
  • Firefox
其他基於 Chromium 或 Firefox 的瀏覽器大多也能正常執行；目前較不建議使用 Apple Safari。
螢幕解析度：至少 1280 × 720 像素以上。
精確指標裝置：需要滑鼠、觸控板或軌跡球以精準繪製節點與桿件。

如何排除問題？

嘗試繼續使用：即使出現警告，橋梁結構設計師仍可能在您目前的裝置上運作（部分功能會自動停用或體驗較差）。您可以在警告視窗中點擊取消直接進入試用。
調整螢幕設定或周邊裝置：若警告指向解析度不足或偵測不到滑鼠，可嘗試以下做法：
  • 檢查作業系統的顯示器設定，將解析度調整為 1280×720 以上（越高越清晰好操作）。
  • 若螢幕較小，可按 F11 將瀏覽器切換為「全螢幕模式」以充分利用畫面空間。
  • 多數平板或觸控裝置皆可外接藍牙或 USB 滑鼠。
更換或更新瀏覽器：若啟動警告指出瀏覽器不支援或缺少 HTML／CSS／WebGL2 功能，建議安裝或更新至最新版 Google Chrome 或 Microsoft Edge。
