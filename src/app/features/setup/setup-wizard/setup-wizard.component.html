設計需求
假設您是交通部門的土木工程師，負責設計一座跨越河谷的雙線道公路桁架橋。您的設計目標如下：
（1）確保橋梁能夠承受自身重量（包含鋼筋混凝土橋面重）以及標準卡車行駛的載重。
（2）在確保結構安全的前提下，盡可能降低工程總成本。
如需查閱完整設計規範，請點擊下方的「說明…」按鈕。

鋼桁架設計步驟：
  1. 點擊「完成」按鈕進入繪圖區。
  2. 繪製節點（Joints）。
  3. 連接桿件（Members）。
  4. 執行載重測試，檢查橋梁結構強度。
  5. 強化載重測試中破壞或細長比不合格的桿件。
  6. 反覆調整並最佳化設計，盡可能降低總成本。

設計提示
橋梁結構設計師（{{ edition }}）能協助您完成上述設計需求。
您在步驟 3 選擇的橋面高程與支承配置將自動套用於繪圖區。系統也會依據您在步驟 4 選擇的橋面重量與卡車載重進行模擬載重測試，驗證結構安全性；若橋梁強度不足，系統將自動標示出需要強化的桿件。
若您正在參加由主辦單位提供「地區競賽代碼」的競賽，您必須使用該競賽指定的場地配置與載重條件。
在此輸入競賽代碼後，繪圖區將自動套用指定的場地與載重條件；接著點擊「下一步」時，設定精靈會自動跳過步驟 3 與步驟 4，直接前往步驟 5。
橋梁總成本為「場地成本」加上「桁架成本」。場地成本顯示於下方；桁架成本則會在您繪製桁架時即時計算。
一般而言，增加場地成本的配置往往有助於降低桁架成本，反之亦然。例如：降低橋面高程雖然會因開挖土方較多而提高場地成本，但也能縮短橋梁跨距、減少鋼材用量。請嘗試在兩者之間取得最佳平衡！
如需進一步了解場地配置選擇，請點擊下方的「說明…」按鈕。
中強度混凝土單價較便宜，但橋面較厚且較重，會增加結構的靜載重，進而提高鋼桁架成本。
高強度混凝土單價較高，但因強度較佳、橋面可做得更薄更輕，較低的橋面重量有助於降低桁架成本。
您也可以選擇左側兩種卡車載重條件之一。
如需更多載重條件說明，請點擊下方的「說明…」按鈕。
範本是標準桁架結構的參考圖樣。選擇範本後，繪圖區會以淺色虛線顯示該結構輪廓，引導您放置節點與桿件，確保設計出的桁架具備結構穩定性。
穩定的桁架是由彼此相連的三角形所組成；不穩定的桁架無法承受任何載重。如需更多結構穩定性說明，請點擊下方的「說明…」按鈕。
標題欄會顯示在繪圖區的右下角，以及列印出的橋梁工程圖上。
請在「設計者」欄位輸入您的姓名，並於「專案編號」輸入辨識代號或名稱。之後也可以隨時在繪圖區直接點擊標題欄修改。
一切準備就緒！點擊下方「完成」按鈕即可開始在繪圖區建立節點與桿件，並隨時進行載重測試與成本最佳化。
標題欄資訊會顯示於繪圖區右下角與列印圖紙上，您之後仍可隨時點擊繪圖區上的標題欄進行修改。
