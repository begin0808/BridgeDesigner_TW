橋梁結構設計師（雲端版）讓任何擁有瀏覽器與滑鼠的使用者都能輕鬆學習結構工程原理，無需像舊版一樣安裝軟體。 橋梁結構設計師（雲端版）注重隱私與安全，所有橋梁設計與結構運算皆直接在您的瀏覽器中執行，不會蒐集個人資料。 本軟體致力於支援大多數主流瀏覽器。建議優先使用 Chromium 核心瀏覽器（例如 Google Chrome 或 Microsoft Edge），Firefox 亦可正常運作。 使用橋梁結構設計師時若遇到異常或錯誤，歡迎向原專案團隊（bridgedesignerteam@gmail.com）或本繁體中文版專案回報，並附上重現問題的步驟。 您可以將設計好的橋梁匯出進行 3D 列印！點選上方選單的檔案 → 匯出 3D 列印 OBJ 檔…，並可點擊說明…查看詳細組裝方式。 一般情況下，橋梁結構設計師（雲端版）只要在同一台電腦上使用，便會自動記住您的工作進度（包含歷史設計版本、復原／重做紀錄等）。若使用公用電腦，請看下一則訣竅！ 若您是在學校電腦教室等共用電腦上使用橋梁結構設計師，離開前建議到上方選單的編輯取消勾選自動記住目前進度，避免下一位同學看到或覆蓋您的設計。 美國西點軍校（West Point）是美國第一所開設正規工程學程的大學。原版橋梁結構設計師最初是西點軍校教授為慶祝建校兩百週年（2002 年）所開發的教學軟體，至今全球累積下載已超過三百萬次。 橋梁結構設計師內建豐富的說明系統，能幫助您探索進階操作並認識真實世界的橋梁工程知識。點選上方選單的說明即可查閱。 您可以在繪圖區直接點擊桿件來選取它，也可以在畫面右側的桿件明細表中點擊對應的編號列。 在繪圖區或桿件明細表中，按住 Ctrl 鍵點擊或拖曳滑鼠即可同時選取多支桿件，方便一次刪除或同時更改多支桿件的材料與尺寸。 點擊右側桿件明細表各欄位頂端的標題，即可依桿件編號、材料、細長比或載重測試結果進行排序，快速找出受力最危險的桿件。 在繪圖區拖曳滑鼠框選多支桿件時：向右拖曳只會選取完全落在框內的桿件；向左拖曳則會選取框內及所有碰觸到框線的桿件。 想加快反覆修改與測試的節奏嗎？可以關閉動畫直接看分析結果：點擊上方選單的測試，取消勾選顯示測試動畫即可。 刪除節點或桿件有兩種方式：（1）先選取物件後，點擊工具列上的刪除按鈕（或按 Delete 鍵）；（2）切換到繪圖工具箱的橡皮擦工具，直接點擊欲刪除的物件。 每次執行載重測試時，系統都會自動記錄一個設計版本。使用上一個版本按鈕即可隨時回到先前的設計狀態。 在載重測試動畫中，橋梁的變形量刻意放大了 20 倍，以利觀察桁架承受載重時的受力行為——真實世界的橋梁並不會彎曲成這樣！ 在載重測試動畫畫面中，點擊半透明的齒輪圖示即可開啟動畫設定，自由關閉變形放大、桿件色彩顯示或背景元素。 在載重測試動畫中，等卡車來回通過兩次（或橋梁倒塌數秒後），鏡頭會自動環繞橋梁飛行，讓您以真實視角欣賞自己的設計；點擊任何視角控制按鈕即可結束環繞。 在相同重量與鋼材種類下，空心方管單價雖比實心方鋼略高，但抵抗壓力與挫屈的效率高出許多，因此受壓桿件通常優先選用空心方管。 在相同重量與鋼材種類下，空心方管與實心方鋼的抗拉效率完全相同；但實心方鋼較便宜，因此受拉桿件通常選用實心方鋼更划算。 在載重測試動畫中，受拉桿件會呈現藍色，受壓桿件會呈現紅色，顏色越鮮豔代表該桿件承受的受力越接近強度極限！ 在載重測試動畫中，點擊半透明的卡車圖示即可切換至「駕駛座視角」，體驗開著卡車通過自己設計的橋梁，並可用滑鼠拖曳環顧四周。 繪製或編輯結構時若不小心做錯了，可以隨時點擊復原按鈕回到上一步，也可以用重做按鈕恢復剛剛復原的操作。 橋梁總成本由四個部分組成：（1）材料成本、（2）接合成本、（3）規格品項成本、（4）場地成本。點擊報告 → 成本計算明細即可查看詳細算式。 如果您是第一次使用橋梁結構設計師，建議先載入標準桁架範本，參考範本虛線學習如何配置節點與桿件來建立穩定的桁架。 繪圖區上的橋面橫梁、混凝土橋面與柏油路面標註若擋到視線，可直接用滑鼠上下拖曳調整它們的位置。 善用快速鍵能大幅提升設計效率！Ctrl+A 全選桿件、Delete 刪除選取項目、Ctrl+Z 復原、Ctrl+Y 重做、Alt+T 執行載重測試、Alt+D 返回繪圖區。 您可以直接用滑鼠拖曳移動節點，所有連接在該節點上的桿件都會自動跟著移動。 您也可以先選取一個節點，再使用鍵盤的方向鍵微調節點位置。 繪圖格線共有三種解析度（粗、中、細）。切換至細格線可以更精細地微調節點位置，進一步最佳化結構形狀與成本。 想確保桁架左右完全對稱，可以在上方選單的檢視勾選對稱參考線作為輔助。 在繪圖區顯示桿件編號，方便與右側桿件明細表一一對照：點擊上方選單檢視 → 桿件編號即可開啟。 若螢幕解析度較低，操作橋梁結構設計師時畫面可能會較擁擠；建議開啟瀏覽器的全螢幕模式（按 F11），或從檢視選單暫時隱藏桿件明細表等元件。 桿件受力分析視窗提供了真實土木工程師設計橋梁時所使用的材料性質、強度曲線與受力細節，歡迎從報告選單開啟探索。 您可以隨時將設計存檔至電腦中（`.bdc` 檔），方便日後重新開啟編輯，或帶到其他電腦繼續完成作品。
