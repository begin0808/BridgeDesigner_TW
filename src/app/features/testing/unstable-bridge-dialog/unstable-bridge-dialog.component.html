橋梁結構分析
🙁 您的結構模型目前不穩定，一起來修正它吧！ 🙂

由於結構不穩定，目前無法執行載重測試。要讓桁架穩定，整個結構必須完全由彼此相連的三角形組成——通常這代表需要補上額外的桿件。

想了解不穩定的原因與修正方法，請參考下方的圖解範例。

準備好返回繪圖區修改時，請點擊「關閉」按鈕。

（1）這座桁架不穩定，因為反白標示的區段是矩形，而非三角形。
（2）矩形框架不具剛性，無法承受載重；沒有桿件能阻止桁架繞著支承點傾倒變形，因此結構不穩定。
（3）修正方式：加入一根斜向桿件，將矩形分割成兩個三角形。現在整個桁架具備剛性並可承受載重，成為穩定結構。

（2）因為結構配置分離，沒有桿件能阻止左右兩半繞著支承點發生旋轉，因此整體結構不穩定。

（1）這座桁架也不穩定，因為中央區段是一個四邊形。這說明「任何四邊形」（不只是矩形）都會造成桁架不穩定。
（2）四邊形框架不具剛性，無法承受任何載重，也無法防止整座桁架繞支承點旋轉，因此結構不穩定。
（3）修正方式：加入一根垂直桿件，將四邊形分割為兩個三角形。現在桁架具備剛性並可承受載重，成為穩定結構。
設計提示：
如果建立穩定桁架遇到困難，建議先使用設計範本：在上方選單點擊「檔案」→「載入範本…」，範本會以虛線引導節點與桿件位置，幫助您完成穩定的桁架設計。
