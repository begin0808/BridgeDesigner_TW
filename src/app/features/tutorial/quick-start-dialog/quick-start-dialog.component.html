1. 桿件顏色代表什麼力？

🔴 紅色：受壓力（Compression）

桿件被兩端往內擠壓，受力越大顏色越深。太細長的受壓桿件容易發生挫屈（彎折）！

🔵 藍色：受拉力（Tension）

桿件被兩端往外拉扯，受力越大顏色越深。抗拉強度只取決於截面積與鋼材種類，不受長度影響。

🟣 洋紅色：細長比過高（Slenderness）

桿件過長過細不符合橋梁規範，必須加粗斷面、改用空心方管或縮短長度。

2. 怎麼看右側「桿件明細表」？

受力／強度比 ＝ 桿件承受的最大內力 ÷ 桿件能承受的極限強度

  • ≤ 1.00：安全通過！越接近 0.90～0.99 代表材料利用越精準省錢。
  • > 1.00：結構破壞！表格會標示紅底（壓力超標）或藍底（拉力超標），請務必補強這些桿件。
  • 小於 0.40：代表這支桿件「用太粗了」，可以縮小尺寸大幅降低總造價！

3. 實心方鋼 vs 空心方管 & 三種鋼材選用祕訣

🧱 實心方鋼 vs 🟦 空心方管

受壓桿件（紅色）優先選「空心方管」！相同重量下，空心方管把材料分布在外部，慣性矩大得多，抗挫屈能力遠勝實心方鋼且更省錢。受拉桿件（藍色）則可依成本挑選較細實心方鋼或高強度鋼。

⚙️ 三種鋼材比較

  • 碳鋼 (CS)：最便宜、強度基本，適合多數受壓或低受力桿件。
  • 高強度低合金鋼 (HSS)：強度高、價格中等，高CP值主力鋼材。
  • 淬火調質鋼 (QTS)：強度最高但單價最貴，適合少數受大拉力的關鍵桿件。

Q1：按下「載重測試」跳出「橋梁結構不穩定」，怎麼辦？

最常見的 3 個原因：(1) 出現沒有斜桿支撐的四邊形（請補畫斜桿切成三角形）；(2) 有節點完全懸空或只接了 1 支桿件；(3) 忘記把兩端橋台或中間橋墩的支承節點連進桁架中。

Q2：出現「細長比檢核未通過」是什麼意思？

代表某支桿件「太長又太細」，在實務上容易因自重或震動彎折。點開右側表格找到洋紅色背景的桿件，將它改成空心方管或加大一兩級尺寸即可解決！

Q3：為什麼載重測試按鈕呈現灰色按不下去？

代表目前畫布上的橋梁還沒有完成最基本的桿件連接（例如尚未畫任何桿件，或橋面預設節點還沒連接）。請先點選節點工具與桿件工具完成桁架繪製。

Q4：想直接看一座會動的範例橋來學習原理？

沒問題！點擊下方「載入範例橋梁來觀察」按鈕，即可開啟內建的 6 座經典桁架橋範例，直接按下「載重測試」觀看受力動畫與成本分析！
